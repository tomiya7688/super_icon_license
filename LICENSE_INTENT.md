# License Intent

This document explains why the Super Icon / すーぱーあいこん assets use the
MIT License. It does not replace the MIT License text.

## Intent

Super Icon exists to be a broadly reusable, low-friction visual asset.

The goal is that users can:

- use it in commercial or non-commercial projects,
- copy and redistribute it,
- modify it,
- bundle it with software,
- use it as a placeholder/default player image,
- replace it later with another character or image.

That is why MIT is used: the asset is intended to be easy to reuse without a
character-specific licensing discussion.

## AI Game Player 1.0

The AI Game Player 1.0 release uses Super Icon as its bundled/default Player
Asset because the first stable release intentionally keeps its project-owned
payload simple and MIT-focused.

This does not mean later AI Game Player releases or other characters must use
MIT.
